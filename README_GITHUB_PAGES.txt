Inventaire forestier - V2.14 vierge pour GitHub Pages

Contenu a déposer a la racine du dépôt GitHub :
- index.html
- style.css
- app.js
- manifest.json
- sw.js
- assets/
- .nojekyll

Cette version est vierge : aucune donnée projet n'est préchargée dans les fichiers.
Les projets, tènements et checklists sont stockés localement dans le navigateur de chaque utilisateur via localStorage.

Mise en ligne GitHub Pages :
1. Dézipper ce fichier.
2. Uploader le contenu du dossier dézippé directement a la racine du dépôt, pas le ZIP.
3. Dans Settings > Pages, choisir Deploy from a branch, branch main, folder /root.
4. Attendre la fin du déploiement dans Actions.

Mise a jour apres déploiement :
- PC : Ctrl + F5.
- Mobile : ouvrir l'app avec Internet, attendre quelques secondes, fermer puis rouvrir.

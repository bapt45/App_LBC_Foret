Inventaire forestier - V2.14.0

Application web/PWA d'inventaire forestier habillée Control Union.

Nouveautés V2.14 :
- gestion de plusieurs projets distincts ;
- page d'accueil avec liste des projets ;
- création, ouverture et suppression de projets ;
- checklist terrain propre à chaque projet ;
- tènements et compteurs propres à chaque projet ;
- bouton Modifier dans le récapitulatif des tènements ;
- possibilité de revenir sur un tènement saisi pour modifier son nom, sa surface, son type, les densités, la durée et les comptages ;
- exports CSV limités au projet actif et incluant le nom du projet.

Installation / mise à jour :
1. Dézipper le dossier.
2. Déposer les fichiers décompressés à la racine du dépôt GitHub Pages.
3. Attendre le déploiement.
4. Ouvrir l'application avec Internet une première fois.
5. Sur PC, faire Ctrl + F5 après mise à jour. Sur mobile, ouvrir avec réseau, attendre quelques secondes, puis fermer/réouvrir l'application.

Les données sont stockées localement dans le navigateur de chaque auditeur.

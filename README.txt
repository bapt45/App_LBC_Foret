Inventaire forestier - Version 2.8.0

Application web/PWA d'inventaire forestier.

Nouveautes V2.8 :
- ajout d'un deuxieme onglet "Checklist terrain" ;
- 16 questions terrain accessibles sur smartphone ;
- reponses Oui / Non / N/A selon le type de question ;
- sauvegarde automatique des reponses de checklist ;
- export CSV separe de la checklist ;
- fonctionnement hors connexion apres premiere ouverture via HTTPS.

Installation GitHub Pages :
1. Dezipper ce dossier.
2. Envoyer les fichiers decomprimes a la racine du depot GitHub.
3. Ne pas envoyer uniquement le fichier ZIP.
4. Attendre la reconstruction GitHub Pages.
5. Ouvrir l'URL une premiere fois avec internet pour mettre a jour le cache hors connexion.

Important : apres mise a jour depuis une ancienne version, faire un rafraichissement complet
(Ctrl+F5 sur PC) ou rouvrir l'application avec internet sur mobile.


Nouveautes V2.8 :
- Checklist terrain : toutes les questions proposent Oui / Non / N/A / Non audité.
- Ajout d'un commentaire facultatif pour chaque question.
- Export checklist CSV enrichi avec une colonne Commentaire.
